Create a new Acorn using the Safebox defaults. Your wallet will open as soon as its relay state and default handle have been verified.

Safebox uses a 12-word recovery mnemonic, defers the backup ceremony, and assigns a public handle derived from the Acorn public key. The mnemonic is temporarily held in this browser's encrypted session. Complete the recovery backup before the session expires or is cleared. The handle can be changed or removed later, and Protected Records can be enabled when needed.
