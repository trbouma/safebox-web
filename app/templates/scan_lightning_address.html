Advisories

Point the camera at a Safebox record-sharing or presentation code, Clear token, NUT-18 Clear payment request, Lightning address or invoice, or GS1 Digital Link, or HTTPS website address. Scanning only acquires the request; Safebox determines the capability from the code before showing the next action.

The camera starts automatically. If access is unavailable, check the browser's camera permission or enter the code manually. Camera access from another device requires Safebox to be served over HTTPS.

EAN, UPC and DataMatrix camera decoding depends on browser support. For GS1 element strings without a GS1 symbology identifier, select GS1 mode explicitly. Preserve ASCII group separators; alternatively paste parenthesized notation such as (01)00057606029096(17)270131(10)693773. Never remove separators between variable-length fields.
