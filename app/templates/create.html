Both options can recover the Acorn. The 24-word option uses 256 bits of generated entropy instead of 128 bits.

Bring your own entropy

Optionally supply exactly 32 bytes of externally generated entropy as 64 hexadecimal characters. This overrides the mnemonic-length choice and produces a 24-word Safebox Acorn mnemonic. Safebox processes the value for this request but does not store it.

Bring your own record-protection entropy

Safebox normally asks Acorn to generate an independent record protection key. Optionally supply a separate 32-byte, cryptographically random value as 64 hexadecimal characters. Acorn derives the key using a record-protection-specific context. This value must not be reused as the wallet entropy. Protected records are not enabled yet; the resulting working key is held only in the protected, authenticated session cookie.
